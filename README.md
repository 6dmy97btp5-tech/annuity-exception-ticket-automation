# Annuity Exception Ticket Automation Tool
Annuity Exception Ticket Automation Tool
AI-assisted workflow automation for annuities trading operations — built for
compliance-critical financial environments.
Overview
This tool was designed and built to replace manual exception ticket processing in LPL
Financial’s Annuities Trading Department. It automates the most time-consuming and
error-prone parts of the workflow — routing, compliance review, and state-specific
regulatory requirements — through a structured, multi-tab HTML interface.
Built by a financial operations professional with direct knowledge of annuities trading
workflows, compliance requirements, and advisor support needs.
Features
Four Funding Type Workflows
New Money / Check
1035 Exchange
Transfer
Funding Through Client Account (FTC)
Automated Email Routing Logic Generates correctly routed exception ticket
emails based on funding type and case details — eliminating manual routing
decisions.
Built-in Compliance Review Each workflow includes regulatory explanations and
compliance checkpoints to reduce processing errors in regulated environments.
